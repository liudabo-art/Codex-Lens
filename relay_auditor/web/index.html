    选择适合的检测

    基础体检：无需官方 Key

    质量任务覆盖约束、代码追踪、错误修复、结构输出及虚拟工具参数。长上下文和推理档位可以单独测；结果说明这些题上的表现。

    官方对照：比较更有依据

    增强配对评测默认 40 对题。官方指纹登记与行为审计另外运行。只有匹配条件才作比较；少量样本与格式失败保留无法判断。

    长期巡检：由你开启

    周期检测按该目标的间隔和活跃条件运行，并共用每日检测预算。延迟和推理 token 数可用于排查问题，判断质量差距需要同题对照。
