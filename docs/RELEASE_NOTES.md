# Codex Lens 0.1.0 · 桌面预览 / Desktop preview

本次提供独立运行的检测器。支持单侧体检、官方同型号对照、按失败侧重试、检测历史和匿名报告。真实模型校准仍在进行，结论适用于本轮采样条件。

| 系统 / System | 下载 / Asset |
| --- | --- |
| Windows 10/11 x64 | `Relay-Auditor-0.1.0-windows-x64-Setup.exe` 或 `Relay-Auditor-0.1.0-windows-x64-portable.zip` |
| macOS Intel | `Relay-Auditor-0.1.0-macos-x64.dmg` |
| macOS Apple Silicon | `Relay-Auditor-0.1.0-macos-arm64.dmg` |
| Ubuntu 24.04 x64 | `Relay-Auditor-0.1.0-linux-x64.deb` 或 `Relay-Auditor-0.1.0-linux-x64.tar.gz` |
| Ubuntu 24.04 ARM64 | `Relay-Auditor-0.1.0-linux-arm64.deb` 或 `Relay-Auditor-0.1.0-linux-arm64.tar.gz` |

下载后用 `SHA256SUMS.txt` 核对文件。Windows 安装包未签名，系统需已有 WebView2。macOS 候选使用临时签名，未做 Apple 公证。Linux 需要 GTK 3、WebKitGTK 4.1 和 glibc 2.39 或更新版本。

Choose the package for your system and CPU. Windows builds are unsigned, and macOS builds are ad hoc signed without Apple notarization.
