# 开发路线 / Development roadmap

## 当前基线

接手开发先读 [开发交接与当前进度](DEVELOPER_HANDOFF.md)，再按 [工作记录](../WORKLOG.md) 与 [验证记录](VERIFICATION.md)核对完成范围和发布状态。交接记录中的下一任务须以实际依赖和验收为准。

当前源码版本为 **0.3.0**：四家完整考试、确切型号参数、逐题证据、历史管理、离线手册、校准预览及研究成绩／失败汇总。公开状态和安装包以对应 Release 为准；先前公开的 `v0.2.0` 保留。各阶段实际软件检查见[验证记录](VERIFICATION.md)。真实研究按型号、家族、配置及卷型独立冻结，付费采样需单独授权，当前没有已校准型号。

统一家族题集注册机制贯穿预估、运行、校准、模拟、先导重建及匿名导出。GPT／DeepSeek 保持 `exam-v2` 兼容；Claude 使用 `claude-exam-v1`、Gemini 使用 `gemini-exam-v1`。确认凭据绑定家族、题集、卷型及双方参数，改变条件须重新预览。旧成绩不重算，旧研究沿原冻结源码复现，不重写清单或放宽哈希校验。

独立工作台、CLI、Python API v2 和本机只读用量观察已经可用。评估 `assessment-v4` 提供单侧和同题对照、按家族选题、重试与预算、匿名历史及 HTML 导出。Windows x64 便携候选已完成本地构建和固定离线 worker 冒烟。macOS、Linux 与 Windows Setup 由独立的原生构建工作流验证。

0.2.0 的 `exam-v2` 为 GPT/Codex 和 DeepSeek 提供可选 120 或 180 题的手动考试。使用合成数据验收评分、交卷、预算和报告。真实校准按家族和卷型独立进行，需另行授权及预算。[能力考试方法](METHODS.md#capability-exam--能力考试)

实验性结论只适用于实际测试的任务和条件。只有经过独立复核的真实试验可支持「已校准」标记。真实采样需要单独授权和预算。 [方法](METHODS.md)

## M3 当前实施：真实采样前的证据完整性

本步落实既定的复考波动、完卷率、无法判断比例、开销及失败结果要求，仍只使用合成数据。真实访问与预算未授权，不进行模型调用。使用现有 Python 标准库、冻结研究及 CLI，不扩展桌面交互或匿名 v2 契约。

- [x] 在 `calibration.py` 采集可选的 `exam_score_counts`，仅含双侧题数、尝试、完成、正确、格式和重试计数。验证期也保留，原始回答及题目不入库。
- [x] 在独立的 `calibration_metrics.py` 校验新计数与配对、请求、重试及先导逐题证据的一致性；旧记录缺字段时保持缺失，不补成零分。
- [x] 给研究报告增加分先导／验证的完卷率、无法判断比例、成绩分布与样本标准差、用量及证据覆盖。仅完整且有成绩证据的试验进入分数分布；不改配对判定、统计门槛或已存成绩。
- [x] 保留匿名固定错误类别、失败侧与题号，并在报告中分组；取消、预算中止、认证及断连不能都丢成同一个未知结果。不接受任意错误正文或私人信息。
- [x] 冻结包含推理档位变化的研究时，核实替代设置被该确切型号与协议支持；不支持时前置拒绝，不自动换档。保留可复现的合法配置。
- [x] 用四家合成客户端验收采集与 CLI 报告、完整／部分卷、格式失分、取消、预算、未知 token、旧记录和源码冻结。同步双语说明、方法、文件指南、日志与实际验证结果。

审阅重点：取消时双方可能已全部作答，但不得产生最终成绩；格式失分计零并属于完整交卷；部分卷不能假造配对边际；没有旧证据不能推导绝对成绩；用户额度不足不改变已确认试卷。此步完成后，真实先导仍按 OpenAI／Anthropic 优先等待独立访问与预算授权。

## 先前开发：先导证据与选题诊断

先前在本地开发分支完善 `calibration-report` 的首批离线检查，当时 272 项 Python 与 22 项前端回归通过。以下实现纳入 0.3.0；后续完整检查见验证记录，真实模型校准另行安排。

1. 从冻结清单重建先导试卷，逐项核对题号、种子、题型、模板、难度和答题侧，拒绝错误配对。旧记录缺少逐题证据时明确标记不可用。
2. 按模板与难度输出计划配对、有效配对、未知、双方都对／都错、官方单侧答对与反向改善；格式失分计零、连接故障保持未知，重试不增加题数。
3. 分差用于描述先导数据，保留覆盖率与试验数；不自动淘汰模板、不改已确认题集、不新增“已校准”结论。通过合成错误证据、缺失及故障样例验收后，再单独安排真实采样。

## 2026-11-13：校准准备与原生家族模块

- GPT/Codex、DeepSeek 增加纯离线研究预览，展示先导／三段验证、单次完整试验的默认预算建议和用户额度缺口。校准命令保存并严格遵守输出上限等冻结条件。
- Claude／Gemini 基础检测模块接入独立原生校准研究，首批限制显式 `assessment-v4`、基础场景、对应原生协议与默认推理／温度。完整考试和真实准确率仍按各家族独立推进。
- 用户当前没有 OpenAI／DeepSeek 官方 Key。本阶段继续软件和合成验收，不启动付费采样。预算建议由用户调整并确认；额度不足时提示、停止后续请求并保留记录，不降低题量或推理要求。
- [实测候选与完整请求计划](CALIBRATION_PILOT_PLAN.md)单独记录待确认的型号、条件和预算。取得官方访问后先做先导、审阅题型，再冻结并跨日期独立验证。无参考历史路径的真实校准仍单独待办，不由双侧模拟或原生接口可用性代替。
